Activity 9.1.1.

For the following examples of relations, give a pair \(x\) and \(y\) such that \(x\sim y\) and a different pair \(w\) and \(z\) such that \(w\not\sim z\text{.}\) (Note, the next activity will require you to work on these same relations, so leave space!)
🔗
(a)
\(\sim = \{(x,y) \in \mathbb{R}\times \mathbb{R}: x<y\}\)
🔗
🔗
(b)
\(\sim\) on \(\mathbb{Z}\) such that \(x\sim y\) if and only if \(x\mid y\)
🔗
🔗
(c)
\(R\) on \(\mathbb{Z}\) such that \(xR y\) if and only if \(x\equiv y\pmod{4}\)
🔗
🔗
(d)
\(\sim\) from \(\{1,2,3\}\) to \(\mathcal{P}(\{1,2,3\}\) such that \(x\sim A\) if \(x\in A\text{.}\)
🔗
🔗
(e)
\(A = \{1,2,3,4,5,6\}\) and \(R = \{ (x,y) \in A\times A: x+y\text{ is even } \}.\)
