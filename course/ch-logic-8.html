    Handout 5.7 Applying Conditional Statements (Using Lemmas)
    

    Here, we think about taking a conditional statement that we know is true, and applying it to some other situation. Sometimes this looks like using a lemma in a proof. Following is a statement of a theorem which can be proven using calculus or precalculus mathematics.
    🔗
    A key component of logical reasoning with conditional statements is known as modus ponens. It works like this:
    🔗
    IF
    🔗
    • you have a conditional statement (of the form “if \(P\text{,}\) then \(Q\)”) that you know is , AND
      🔗
      🔗
    • you can establish that the hypothesis \(P\) is , THEN
      🔗
      🔗
    • it necessarily follows that the conclusion \(Q\) .
      🔗
      🔗
    🔗
    Use this reasoning in what follows.
    🔗

    Activity 5.7.1.

    In calculus, we establish that the following conditional statement is true:
    🔗
    If \(f\) is any function such that \(f\) is differentiable at the real number \(x = a\text{,}\) then \(f\) is continuous at \(x = a\text{.}\)
    🔗
    🔗
    What can we conclude, if anything about the following four functions?
    🔗

    (a)

    A function \(g\) that we know is differentiable at \(x = 2\text{.}\)
    🔗
    🔗

    (b)

    A function \(r\) that we know is not differentiable at \(x=-5\text{.}\)
    🔗
    🔗

    (c)

    A function \(h\) that we know is continuous at \(x = 3\text{.}\)
    🔗
    🔗

    (d)

    A function \(h\) that we know is not continuous at \(x = -1\text{.}\)
    🔗
    🔗
    🔗

    Theorem 5.7.1.

    If \(f\) is a quadratic function of the form \(f(x) = ax^2 +bx + c\) where \(a,b,c\in\mathbb{R}\) and \(a<0\text{,}\) then the function \(f\) has a maximum value when \(x= \frac{-b}{2a}\text{.}\)
    🔗
    🔗

    Activity 5.7.2.

    Using only Theorem 5.7.1, what can be concluded about the functions given by the following formulas?
    🔗

    (a)

    \(g(x) = -8x^2 +5x-2\)

    🔗

    (b)

    \(h(x)=-\frac{1}{3}x^2 + 3x\)
    🔗
    🔗

    \(k(x) = 8x^2 -5x-7\)
    🔗

    \(f(x) = -4x+2\)
