    Handout 9.3 Equivalence Classes
    

    Definition 9.3.1.

    Let \(\sim\) be an equivalence relation on a nonempty set of \(A\text{.}\) Then the equivalence class of of \(a\) determined by \(\sim\) is
    \begin{equation*} [a]_{\sim} = \{x\in A \mid x \sim a \} . \end{equation*}
    🔗
    🔗

    Theorem 9.3.2. Equivalence Classes Partition.

    Let \(A\) be a nonempty set and let \(\sim\) be an equivalence relation on \(A\text{.}\) Then
    🔗
    1. For each \(a\in A\text{,}\) \([a]\) is nonempty (in particular, \(a\in [a]\) ).
      🔗
      🔗
    2. For each \(a,b\in A\text{,}\) \(a\sim b\) if and only if \([a]=[b]\text{.}\)
      🔗
      🔗
    3. For each \(a,b\in A, [a] =[b]\) or \([a] \cap [b] = \emptyset\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Activity 9.3.1. (Working with equivalence classes).

    (a)

    Let \(A = \{0,1,2,3,\dots, 999, 1000\}\) and define \(\sim\) by
    🔗
    For \(x,y\in A\text{,}\) \(x\sim y\) if and only if \(x\) and \(y\) have the same number of digits.
    🔗
    This is an equivalence relation (briefly think about why). Determine all the distinct equivalence classes determined by \(\sim\text{.}\)
    🔗
    🔗

    (b)

    Recall that \(\mathcal{M}_{2\times 2}(\mathbb{R})\) is the set of all \(2\times 2\) matrices and that if \(A = \begin{bmatrix} a \amp b \\ c \amp d\end{bmatrix}\) then the determinant of \(A\) is given by \(\det(A) = ad-bc\text{.}\) Define \(\sim\) by,
    🔗
    For all \(A,B \in \mathcal{M}_{2\times 2}(\mathbb{R})\text{,}\) \(A\sim B\) if and only if \(\det(A) = \det(B)\text{.}\)
    🔗
    (i)
    Find two matrices \(A\) and \(B\) such that \(A\sim B\text{.}\)
    🔗
    🔗
    (ii)
    Is \(\sim\) an equivalence relation? (Briefly think about it, don’t need to prove.)
    🔗
    🔗
    (iii)
    Let \(X = \begin{bmatrix} 0 \amp 0 \\ 0 \amp 0 \end{bmatrix}\text{.}\) Find two elements of \([X]_{\sim}\text{.}\)
     8 
    Challenge Question: Can you find the entire equivalence class?
    🔗
    🔗
    🔗

    Activity 9.3.2. Equivalence Classes for Congruence Modulo \(3\)- MTH 350.

    This is a preview activity taken from the 5th chapter of the modern algebra text used by many professors at GVSU.
    🔗
    For each integer \(a\text{,}\) let \([a]_3\) denote the set of all integers that are congruent to \(a\) modulo \(3\text{.}\) Note this is the equivalence class of \(a\) under the congruence modulo \(3\) equivalence relation.
    🔗

    (a)

    Determine \([0]_3, [1]_3, [2]_3, [3]_3, [4]_3,\) and \([5]_3\text{.}\)
    🔗
    🔗

    (b)

    What is the remainder when \(734\) is divided by \(3\text{?}\) Which, if any, of the sets \([0]_3\text{,}\) \([1]_3\text{,}\) and \([2]_3\) contain \(734\text{?}\)
    🔗
    🔗

    (c)

    Which elements belong to \([0]_3\cap [1]_3\text{?}\) What about \([0]_3\cap [2]_3\text{,}\) or \([1]_3\cap [2]_3\text{?}\)
    🔗
    🔗

    (d)

    What familiar set is \([0]_3\cup [1]_3 \cup [2]_3\) equal to, and why?
    🔗
    🔗

    (e)

    Based on your answers above, make as many conjectures as you can about \([0]_3, [1]_3, [2]_3, [3]_3, \) \([4]_3,[5]_3,\dots\) (the equivalence classes of congruence modulo \(3\) ).
    🔗
    🔗
    🔗

    Congruence Classes and Congruence Arithmetic.

    If the equivalence relation is congruence, then we use the term congruence class rather than equivalence class. The great thing about congruence classes is that you can add and multiply them in a natural way.
    🔗

    Definition 9.3.3.

    Let \(a,b\in\mathbb{Z}\) and \(n\in\mathbb{N}\text{.}\) Then
    \begin{equation*} [a]_n +_n [b]_n = [a+b]_n \end{equation*}
    and
    \begin{equation*} [a]_n\cdot_n [b]_n = [a \cdot b]_n\text{.} \end{equation*}
    🔗
    🔗
    This may seem obvious to you, but there are some very subtle things going on. Perhaps the weirdest is that \([a]_n\) is really a set, an infinite set. So what you’re actually doing is adding and multiplying infinite sets.
    🔗
    🔗

    Example 9.3.4.

    What is \([1]_3 +_3 [2]_3 \text{?}\) What is \([2]_3 \cdot_3 [2]_3 \text{?}\)
    🔗
    🔗
    Notice that we’ve only used the congruence classes \([0]_3, [1]_3,\) and \([2]_3\) since these are the only distinct congruence classes modulo \(3\text{.}\) We typically let \(\Z_3 = \{[0]_3, [1]_3,[2]_3\}\text{.}\) Also, note \([2]_3 \cdot [2]_3 = [4]_3\text{.}\) However, \([4]_3=[1]_3\) so we choose \(1\) to be our representative of that congruence class.
    🔗
    Here are are addition and multiplication tables when we consider congruence modulo \(3\text{:}\)
    🔗
    \(+_{3}\) \([0]_{3}\) \([1]_{3}\) \([2]_{3}\)
    \([0]_{3}\) \([0]_3\) \([1]_3\) \([2]_3\)
    \([1]_{3}\) \([1]_3\) \([2]_3\) \([0]_3\)
    \([2]_{3}\) \([2]_3\) \([0]_3\) \([1]_3\)
    \(\cdot_{3}\) \([0]_{3}\) \([1]_{3}\) \([2]_{3}\)
    \([0]_{3}\) \([0]_3\) \([0]_3\) \([0]_3\)
    \([1]_{3}\) \([0]_3\) \([1]_3\) \([2]_3\)
    \([2]_{3}\) \([0]_3\) \([2]_3\) \([1]_3\)

    Activity 9.3.3.

    (a)

    Complete the addition and multiplication tables for \(\mathbb{Z}_4\text{,}\) \(\mathbb{Z}_5\text{,}\) \(\mathbb{Z}_6\) and \(\mathbb{Z}_7\) (you don’t have to write all the [ ]’s but do pick the representative that is in that \(\mathbb{Z}_n\text{.}\) What do you notice? What do you wonder?
    🔗
    🔗

    (b)

    Are the following statements true or false? Why?
    🔗
    (i)
    For all \([a], [b] \in \mathbb{Z}_5\text{,}\) if \([a] \ne [0]\) and \([b] \ne [0]\text{,}\) then \([a] \cdot_5 [b] \ne [0]\text{.}\)
    🔗
    🔗
    (ii)
    For all \([a], [b] \in \mathbb{Z}_6\text{,}\) if \([a] \ne [0]\) and \([b] \ne [0]\text{,}\) then \([a] \cdot_6 [b] \ne [0]\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Activity 9.3.4.

    Sometimes math competition problems will ask seemingly tough questions, like what is the remainder of \(2^{100}\) when divided by \(6\text{.}\) Try to find the answer to this question, by translating into modular arithmetic/congruence classes and doing some smaller cases. E.g., what’s \([2]_{6}^1\text{?}\) \([2]_{6}^2\text{?}\) \([2]_{6}^3\text{?}\) \([2]_{6}^4\text{?}\) What do these tell you about the remainder of \(2^x\) when divided by \(6\text{.}\)
    🔗
    🔗

    Activity 9.3.5.

    In \(\mathbb{Z}_5\text{,}\) solve each of the following equations, keeping in mind that the solution to any equation is the set of all values that make the equation true. Here, “=” means equality as congruence classes. Note, order of operations for \(+_5\) and \(\cdot_5\) are the same as for “regular” addition and multiplication, \(+\) and \(\cdot\text{,}\) in the following way: in the absence of parentheses, we multiply before we add.
    🔗
    Find all \(x\in\mathbb{Z}_5\) such that:
    🔗

    (a)

    \(x^2 +_5 [1] = [0]\)
    🔗
    🔗

    (b)

    \([3] \cdot_5 x +_5 [2] = [0]\)
    🔗
    🔗

    (c)

    \(x^2 +_5 [3] \cdot_5 x= [3]\)
