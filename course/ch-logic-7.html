    Handout 5.6 English is hard!
    

    English is hard!

    As we’ve seen, there are many many ways to write a conditional statement. For example, “if \(P\) then \(Q\)” can be written as “\(P\) implies \(Q\)” or “\(Q\) if \(P\)” or “\(P\) only if \(Q\)” and more. (See page 211 of your textbook.) This is similar for the universal and existential quantifiers. For example, instead of “for all”, we might say “for any”, or “for each”. And instead of “there exists” we could say “there is”. There’s also an idea of “hidden quantifiers”. E.g., sometimes instead of starting “for all” we start with “if” and it has the same meaning.
    🔗
    In general, to negate a statement, it’s a good idea to write the statement using symbols, including any hidden quantifiers. On the other hand, sometimes translating a statement into different words, can be easier to interpret.
    🔗
    🔗

    Example 5.6.1.

    The statement \((\forall x\in\mathbb{R})(x^2\ge 0)\) can be said as
    • For each real number \(x\text{,}\) \(x^2\ge 0\text{.}\)
      🔗
      🔗
    • The square of every real number is at least \(0\) >.
      🔗
      🔗
    • The square of a real number is at least \(0\text{.}\)
      🔗
      🔗
    • If \(x\) is a real number, then \(x^2\ge 0\text{.}\)
      🔗
      🔗
    🔗
    The last statement, is a conditional statement, that “hides” the universal quantifier.
    🔗
    🔗

    Example 5.6.2.

    The statement \((\exists x\in \mathbb{R})(x^2 = 5)\) can be said as
    🔗
    • There exists a real number \(x\) such that \(x^2=5\text{.}\)
      🔗
      🔗
    • \(x^2=5\) for some real number \(x\)
      🔗
      🔗
    • There is some real number whose square is \(5\)
      🔗
      🔗
    • \(x^2=5\) has a real number solution.
      🔗
      🔗
    🔗
    🔗

    Activity 5.6.1.

    Here’s some statements with hidden quantifiers, hidden conditional statements, or translated into other words. Rewrite the sentences as directed.
    🔗

    (a)

    If a function \(y=f(x)\) is continuous at \(x=a\text{,}\) then the function is differentiable at \(x=a\text{.}\) Rewrite with a universal quantifier.
    🔗
    🔗

    (b)

    The equation \(x^3 + x =0 \) has a solution. Rewrite with an existential quantifier.
    🔗
    🔗

    (c)

    Every natural number is a perfect square. Rewrite with a universal and existential quantifier.
    🔗
    🔗

    (d)

    Every real number can be squared. Rewrite with a universal and existential quantifier.
    🔗
    🔗

    (e)

    No basketball players also play tennis. Rewrite as a conditional statement.
    🔗
    🔗

    (f)

    Any prime number is not followed by a perfect square. Rewrite as a conditional statement.
    🔗
    🔗
    🔗

    Activity 5.6.2.

    Let \(a\) be a real number and let \(f\) be a real-valued function defined on an interval containing \(x=a\text{.}\) Consider the following conditional statement:
    🔗
    If \(f\) is differentiable at \(x=a\text{,}\) then \(f\) is continuous at \(x=a\text{.}\)
    🔗
    Let \(P\) be “\(f\) is differentiable”, and \(Q\) be “\(f\) is continuous”. So the above statement is \(P\implies Q\text{.}\) For each of the following write in symbols, using \(P\text{,}\) \(Q\text{,}\) and logical operators. Then, determine which statements are equivalent to \(P\implies Q\) and which are the negation? (Some may be neither.)
    🔗

    (a)

    If \(f\) is continuous at \(x=a\text{,}\) then \(f\) is differentiable at \(x=a\text{.}\)
    🔗
    🔗

    (b)

    If \(f\) is not differentiable at \(x=a\text{,}\) then \(f\) is not continuous at \(x=a\text{.}\)
    🔗
    🔗

    (c)

    If \(f\) is not continuous at \(x=a\text{,}\) then \(f\) is not differentiable at \(x=a\text{.}\)
    🔗
    🔗

    (d)

    \(f\) is not differentiable at \(x=a\) or \(f\) is continuous at \(x=a\)
    🔗
    🔗

    (e)

    \(f\) is not continuous at \(x=a\) or \(f\) is differentiable at \(x=a\)
    🔗
    🔗

    (f)

    \(f\) is differentiable at \(x=a\) and \(f\) is not continuous at \(x=a\text{.}\)
    🔗
    🔗
    🔗
