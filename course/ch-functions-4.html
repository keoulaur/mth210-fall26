    Handout 8.3 Functions - Compositions and Inverses
    

    Definition 8.3.1.

    Let \(A,B\text{,}\) and \(C\) be sets, \(g: A\to B\) and \(f:B\to C\text{.}\) Then the composition function is denoted \(f\circ g\) and is defined as thus:
    \begin{equation*} (f\circ g): A\to C \hspace{.2in} \text{ where } \hspace{.2in} (f\circ g)(a) = f(g(a)). \end{equation*}
    🔗
    This is read as “\(f\) composed with \(g\)” or “\(f\) of \(g\)”. Note \(g\) composed with \(f\) is usually very different than \(f\) composed with \(g\text{.}\)
    🔗
    🔗

    Definition 8.3.2.

    For a set \(A\text{,}\) the identity function on \(A\) is the function. That is,
    \begin{equation*} i_A: A\to A \,\,\text{ where } \,\, i_A(x) = x \text{ for every } x\in A. \end{equation*}
    🔗
    🔗

    Definition 8.3.3.

    The inverse of a function \(f: A\to B\text{,}\) if it exists, is the function \(f^{-1}: B\to A\) such that \(f^{-1}\circ f = i_A\) and \(f\circ f^{-1} = i_B\text{.}\)
    🔗
    🔗

    Corollary 8.3.7.

    Suppose \(A,B,\) and \(C\) are sets, \(g:A \to B\) is bijective and \(f:B\to C\) is bijective. Then \(f\circ g\) is bijective.
    🔗
    🔗

    Proof.
    Suppose \(f\) and \(g\) are bijections. Then \(f\) and \(g\) are both injections and surjections. So by Theorem 8.3.5 and Theorem 8.3.6, \(f\circ g\) is an injection and a surjection.
    🔗
    🔗
    It is also true that if \(f\circ g\) is an injection then \(g\) is an injection, and if \(f\circ g\) is a surjection then \(f\) is a surjection.
    🔗

    Theorem 8.3.10.

    A function \(f: A\to B\) is invertible if and only if \(f\) is a bijection.

    Activity 8.3.7.

    One of the big ideas of inverse functions is that they allow us to “undo” functions. E.g., \(\log_2(x)\) undoes \(2^x\) in the sense that \(\log_2(2^x) = x = 2^{\log_2(x)}\text{.}\) Similarly, \(\arcsin(x)\) undoes \(\sin(x)\text{.}\) This activity is going to ask, if we can take square roots and cube roots modulo \(5\text{.}\)
    🔗

    (a)

    Define \(f: \mathbb{R} \to \mathbb{R}\) by \(f(x) = x^2\text{.}\) Then we might say the inverse is \(g: \mathbb{R} \to\mathbb{R}\) where \(g(x) = \sqrt{x}\text{.}\) Is \(g\) a function? Why or why not? What about if we change \(f\) to \(x^3\) and \(g\) to \(\sqrt[3]{x}\text{?}\)
    🔗
    🔗

    (b)

    Let \(R_5 = \{0,1,2,3,4\}\) for the rest of the questions.
    🔗
    Define \(h: R_5 \to R_5\) by \(h(x)=x^2 \pmod{5}\text{.}\) Find \(h(a)\) for all \(a\in R_5\text{.}\) Does \(h\) have an inverse function?
    🔗
    🔗

    (c)

    Define \(j: R_5 \to R_5\) by \(j(x)=x^3 \pmod{5}\text{.}\) Find \(j(a)\) for all \(a\in R_5\text{.}\) Does \(j\) have an inverse function?
    🔗
    🔗

    (d)

    Define \(k: R_5 \to R_5\) by \(k(x)=x^3 -2 \pmod{5}\text{.}\) Can you find a formula for \(k^{-1}(x)\text{?}\)
