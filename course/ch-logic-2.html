    Vocabulary and Notation.

    Word Symbol Meaning
    Statement A statement is a sentence or mathematical expression
    that is true or false.
    Open Sentence An open sentence is a sentence or mathematical expression
    which does not have a truth value, depends on some unknown,
    becomes a statement when the unknown is specified.
    And \(\wedge\) \(P\wedge Q\) is true when both \(P\) and \(Q\) are true.
    Or \(\vee\) \(P \vee Q\) is true when at least one of \(P\) or \(Q\) is true.
    Not (or Negation) \(\sim\) \(\neg P \) has the opposite truth value of \(P \)
    Conditional Statement
    “If...then”    		 \(\implies\) \(P\implies Q\) means “If \(P\) then \(Q\)” and is only false
    in situations where \(P\) is true and \(Q\) is false.
    Hypothesis In a conditional statement “If \(P\) then \(Q\)”, \(P\) is the hypothesis.
    Conclusion In a conditional statement “If \(P\) then \(Q\)”, \(Q\) is the conclusion.
    Biconditional Statement
    “if and only if”, or “iff”    		 \(\Leftrightarrow\) A biconditional statement is of the form \(P\) if and only if \(Q\text{.}\)
    It means \(P\implies Q\) and \(Q\implies P\text{.}\)
    Converse The converse of \(P\implies Q\) is \(Q\implies P\text{.}\)
    Logically Equivalent \(\Leftrightarrow\) A statement is logically equivalent to another statement if they
    have the same truth value on all possible inputs.
    E.g., \(\sim (P \wedge Q) \Leftrightarrow \sim P \,\vee \sim Q\) by DeMorgan’s Laws
    For all \(\forall\) Also, ``For ever", ``For each"
    There exists \(\exists\) Also ``For some"
    Quantifier Indicates the number or quantity of our objects.
    \(\forall\) is the universal quantifier and
    \(\exists\) is the existential quantifier
    Tautology A statement that is true no matter what, e.g., \(S\vee \sim S\)
    Contradiction A statement that is never true, e.g., \(S\wedge \sim S\)
    Converse The converse of \(P\implies Q\) is \(Q\implies P\text{.}\)
    Contrapositive The contrapositive of \(P\implies Q\) is \(\sim Q \implies \sim P\text{.}\)

    Conditional Statements, Biconditional Statements.

    We use conditional and biconditional statements in every day life! E.g., “You can only get the math department scholarship if you apply”, or “You get SWS credit for MTH 210 pass if and only if you earn a C or better”.

    🔗

    Conditional and Biconditional Statement Truth Tables.

    Conditional statement truth tables can be a little tricky because we have to think abou the truth value of “If \(P\) then \(Q\)” when \(P\) is false. Like we could say “if the moon is made of cheese then DocK is a millionaire.” This statement is considered true no matter what, because the hypothesis is false.

    The Converse and the Contrapositive.

    The converse and the contrapositve are similar sounding words, but differ in very important ways.
    🔗
    • The converse of \(P\implies Q\) is \(Q\implies P\text{.}\)

      🔗
    • The contrapositive of \(P\implies Q\) is \(Q\implies P\text{.}\)

    Negating Conditional Statements.

    The negation of the statement \(P\) is the statement “not \(P\)” and is denoted by \(\sim P\text{.}\) The negation of \(P\text{,}\) \(\sim P\text{,}\) is true only when \(P\) is false, and \(\sim P\) is false only when \(P\) is true.
    🔗
    We want to be able to write the negations of statements written in English, so that we can get the statement of opposite truth value. This will be helpful when doing proofs by contradiction.

    🔗

    Applying Conditional Statements.

    Here, we think about taking a conditional statement that we know is true, and applying it to some other situation. Sometimes this looks like using a lemma in a proof. Following is a statement of a theorem which can be proven using calculus or precalculus mathematics.
    🔗

    Theorem 5.1.3.

    If \(f\) is a quadratic function of the form \(f(x) = ax^2 +bx + c\) where \(a,b,c\in\mathbb{R}\) and \(a<0\text{,}\) then the function \(f\) has a maximum value when \(x= \frac{-b}{2a}\text{.}\)
