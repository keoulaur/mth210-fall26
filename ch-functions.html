    Chapter 8 Functions

    Handout Functions Introduction
    

    Definition 8.1.

    Given a pair of sets \(A\) and \(B\text{,}\) suppose that each element \(x\in A\) is associated in some way, to a unique element of \(B\text{,}\) which we denote \(f(x)\text{.}\) Then \(f\) is said to be a function from \(A\) to \(B\text{.}\) This is often denoted
    \begin{equation*} f: A\to B. \end{equation*}
    Furthermore, \(A\) is called the domain of \(f\text{,}\) and \(B\) is called the codomain of \(f\text{.}\) The set \(\{f(x): x\in A\}\) is called the range of \(f\text{.}\)
    🔗
    🔗

    Definition 8.2.

    A function \(f: A\to B\) is injective (or one-to-one ) if for all \(a_1,a_2\in A\text{,}\) if \(f(a_1) = f(a_2)\) then \(a_1 = a_2\text{.}\)
    🔗
    A function \(f: A\to B\) is surjective (or onto ) if, for every \(b\in B\text{,}\) there exists some \(a\in A\) such that \(f(a) = b\text{.}\)
    🔗
    A function \(f: A\to B\) is bijective if, \(f\) is both injective and surjective.
    🔗
    🔗

    Definition 8.3.

    If \(f:A\to B\) and \(a\in A\) then the element \(B\) that is associated with \(a\) is denoted by \(f(a)\) and is called the image of \(a\) under \(f\). If \(f(a)=b\) with \(b\in B\) then \(a\) is called a pre-image of \(b\) under \(f\). If we say the pre-image of \(b\) under \(f\) then we are referring to the set of all pre-images.
    🔗
    🔗

    Theorem 8.11.

    Let \(f: \R - \{1\} \to \R - \{0\}\) be defined by \(f(x) = \dfrac{1}{1-x}\) for all \(x \in \R - \{1\}\text{.}\) Then \(f\) is a bijection.
    🔗
    🔗

    Proof.
    Let \(f: \R - \{1\} \to \R - \{0\}\) be defined by \(f(x) = \dfrac{1}{1-x}\) for all \(x \in \R - \{1\}\text{.}\) We will prove that \(f\) is a bijection by proving that it is both a surjection and an injection.
    🔗
    We will first show that \(f\) is a surjection. So, let \(z \in \mathbb{R} - \{0\}\) be any element of the codomain of \(f\text{.}\) Let \(x = \frac{z-1}{z}\text{.}\) We will show that \(x \in \R - \{1\}\) and that \(f(x) = z\text{.}\)
    🔗
    We begin by showing that \(x\) is in the domain of \(f\text{.}\) To do this, we will show that \(x \in \R\) and \(x \neq 1\text{.}\) Real numbers are closed under subtraction and division (as long as they are nonzero), and by assumption \(z \neq 0\text{,}\) so \(x \in \mathbb{R}\text{.}\) Next we will show that \(x \neq 1\text{.}\) To see this, suppose that \(x = 1\text{.}\) Using algebra, we find that \(1 = \frac{z-1}{z}\text{,}\) which simplifies to \(0 = -1\text{,}\) a contradiction. Thus \(x \neq 1\text{,}\) and so \(x \in \mathbb{R} - \{1\}\text{.}\)
    🔗
    Now we will show that \(f(x) = z\text{.}\) Using algebra,
    \begin{align*} f\left(\frac{z-1}{z}\right) \amp= \dfrac{1}{1 - \left(\frac{z-1}{z}\right)} \\ \amp= \dfrac{1}{\frac{z}{z} - \frac{z-1}{z}} \\ \amp= \dfrac{1}{\frac{z- (z-1)}{z}} \\ \amp= \dfrac{1}{\frac{1}{z}} = z. \end{align*}
    🔗
    Thus for each \(z\) in the codomain of \(f\text{,}\) there exists \(x = \frac{z-1}{z}\) in the domain of \(f\) such that \(f(x) = z\text{.}\) Therefore by definition, \(f\) is a surjection.
    🔗
    We will now show that \(f\) is an injection. So, suppose that \(f(x) = f(y)\) for some \(x, y \in \mathbb{R} - \{1\}\text{.}\) We will show that \(x = y\text{.}\) Using algebra,
    \begin{align*} f(x) \amp= f(y) \\ \dfrac{1}{1-x} \amp= \dfrac{1}{1-y} \\ 1-x \amp= 1-y \\ x \amp= y. \end{align*}
    Thus, for all \(x\) and \(y\) in the domain of \(f\text{,}\) whenever \(f(x) = f(y)\text{,}\) we must have \(x = y\text{.}\) Therefore \(f\) is an injection.
    🔗
    Because we have shown that \(f\) is both a surjection and an injection, we have shown that \(f\) is a bijection.

    Handout Functions - Compositions and Inverses
    

    Definition 8.12.

    Let \(A,B\text{,}\) and \(C\) be sets, \(g: A\to B\) and \(f:B\to C\text{.}\) Then the composition function is denoted \(f\circ g\) and is defined as thus:
    \begin{equation*} (f\circ g): A\to C \hspace{.2in} \text{ where } \hspace{.2in} (f\circ g)(a) = f(g(a)). \end{equation*}
    🔗
    This is read as “\(f\) composed with \(g\)” or “\(f\) of \(g\)”. Note \(g\) composed with \(f\) is usually very different than \(f\) composed with \(g\text{.}\)
    🔗
    🔗

    Definition 8.13.

    For a set \(A\text{,}\) the identity function on \(A\) is the function. That is,
    \begin{equation*} i_A: A\to A \,\,\text{ where } \,\, i_A(x) = x \text{ for every } x\in A. \end{equation*}
    🔗
    🔗

    Definition 8.14.

    The inverse of a function \(f: A\to B\text{,}\) if it exists, is the function \(f^{-1}: B\to A\) such that \(f^{-1}\circ f = i_A\) and \(f\circ f^{-1} = i_B\text{.}\)
    🔗
    🔗

    Define \(f: \mathbb{R} \to \mathbb{R}\) by \(f(x) = x^2\text{.}\) Then we might say the inverse is \(g: \mathbb{R} \to\mathbb{R}\) where \(g(x) = \sqrt{x}\text{.}\) Is \(g\) a function? Why or why not? What about if we change \(f\) to \(x^3\) and \(g\) to \(\sqrt[3]{x}\text{?}\)

    (b)

    Let \(R_5 = \{0,1,2,3,4\}\) for the rest of the questions.
    🔗
    Define \(h: R_5 \to R_5\) by \(h(x)=x^2 \pmod{5}\text{.}\) Find \(h(a)\) for all \(a\in R_5\text{.}\) Does \(h\) have an inverse function?
    🔗
