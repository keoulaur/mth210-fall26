    Handout 5.5 Negating
    

    The negation of the statement \(P\) is the statement “not \(P\)” and is denoted by \(\sim P\text{.}\) The negation of \(P\text{,}\) \(\sim P\text{,}\) is true only when \(P\) is false, and \(\sim P\) is false only when \(P\) is true.
    🔗
    We want to be able to write the negations of statements written in English, so that we can get the statement of opposite truth value. This will be helpful when doing proofs by contradiction.
    🔗

    Activity 5.9.

    Recall that \(\forall\) means “for all” and \(\exists\) means “there exists”. When we use “there exists” we usually follow it with a “such that”. Also, there exist \(x,y\) (no s), but there exists \(x\) (with an s).

    For all integers \(x\text{,}\) \(x\) is a multiple of 2.

    🔗

    (b)

    There exists an integer \(x\) such that \(x\) is a multiple of 2.

    What do the above say about the negations of “for all” and “there exists”?

    Negations.

    Negating a statement should result in the statement having the opposite truth value. Whenever the original statement is true, the negation should be false, and whenever the original statement is false, the negation should be true. Below are some rules for negating statements.
    🔗
    🔗
    Logical Connector In words Negate! Negation distributed In words
    \(\forall x\in A\) For all \(x\) in \(A\) \(\sim(\forall x\in A)\) \(\exists x\in A\) There exists \(x\) in \(A\text{.}\)
    \(\exists x \in A\) There exists \(x\) in \(A\) \(\sim(\exists x \in A)\) \(\forall x\in A\) For all \(x\) in \(A\)
    \(P\vee Q\) \(P\) or \(Q\) \(\sim (P\vee Q)\) \(\sim P \wedge \sim Q\) Not \(P\) and not \(Q\)
    \(P\wedge Q\) \(P\) and \(Q\) \(\sim(P\wedge Q)\) \(\sim P \vee \sim Q\) Not \(P\) or not \(Q\)
    \(P\implies Q\) If \(P\) then \(Q\) \(\sim(P\implies Q)\) \(P\wedge \sim Q\) \(P\) and not \(Q\text{.}\)
    \(\sim P\) Not \(P\) \(\sim(\sim P)\) \(P\) \(P\)
    🔗

    Activity 5.11. Practice negating.

    Negate the following statements.
    🔗

    (a)

    For all integers \(n\text{,}\) if \(n\) is positive, then \(n^2 - n + 11\) is prime.

    🔗

    (b)

    For all integers \(a\) and \(b\text{,}\) if \(a\equiv 1\pmod{3}\) and \(b\equiv 2\pmod{3}\) then \(a+b\equiv 0\pmod{3}\text{.}\)
    🔗
    🔗

    (c)

    For each real number \(x\text{,}\) if \(x\ge 0\) then \(x^2\ge 0 \) and \(\sqrt{x^2} = x\text{.}\)
    🔗
    🔗

    (d)

    There are real numbers \(a\) and \(b\) such that \(ab\neq \sqrt{a^2b^2}\text{.}\)
    🔗
    🔗

    (e)

    For every pair of real numbers \(x\) and \(y\text{,}\) if \(x<y\) then there exists a rational number \(q\) such that \(x<q<y\text{.}\)

    🔗

    (f)

    For every line \(\ell\) and every point \(P\text{,}\) if \(P\) is not on \(\ell\text{,}\) then there exists a unique line \(m\) through \(P\) that is parallel to \(\ell\text{.}\)
