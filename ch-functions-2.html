    Handout 8.1 Functions Introduction
    

    Definition 8.1.

    Given a pair of sets \(A\) and \(B\text{,}\) suppose that each element \(x\in A\) is associated in some way, to a unique element of \(B\text{,}\) which we denote \(f(x)\text{.}\) Then \(f\) is said to be a function from \(A\) to \(B\text{.}\) This is often denoted
    \begin{equation*} f: A\to B. \end{equation*}
    Furthermore, \(A\) is called the domain of \(f\text{,}\) and \(B\) is called the codomain of \(f\text{.}\) The set \(\{f(x): x\in A\}\) is called the range of \(f\text{.}\)
    🔗
    🔗

    Definition 8.2.

    A function \(f: A\to B\) is injective (or one-to-one ) if for all \(a_1,a_2\in A\text{,}\) if \(f(a_1) = f(a_2)\) then \(a_1 = a_2\text{.}\)
    🔗
    A function \(f: A\to B\) is surjective (or onto ) if, for every \(b\in B\text{,}\) there exists some \(a\in A\) such that \(f(a) = b\text{.}\)
    🔗
    A function \(f: A\to B\) is bijective if, \(f\) is both injective and surjective.
    🔗
    🔗

    Definition 8.3.

    If \(f:A\to B\) and \(a\in A\) then the element \(B\) that is associated with \(a\) is denoted by \(f(a)\) and is called the image of \(a\) under \(f\). If \(f(a)=b\) with \(b\in B\) then \(a\) is called a pre-image of \(b\) under \(f\). If we say the pre-image of \(b\) under \(f\) then we are referring to the set of all pre-images.
    🔗
    🔗

    Let’s do some examples. Draw an arrow diagram, or write down a function formula, for each of the following.

    Activity 8.7.

    For each of the following functions, in addition to answering the given questions you should determine:
    🔗
    the domain, codomain, and range,
    🔗
    and then determine if they are injections, surjections, or bijections.
    🔗

    (a)

    For all \(x\in \mathbb{R}\text{,}\) \(f(x) = x^2-9\text{.}\) What is the image of \(2\text{?}\) of \(20\text{?}\) What is the pre-image of \(0\text{?}\) of \(-10\text{?}\)
    🔗
    🔗

    (b)

    For all people in the world, B(person) = person’s birthday. (Just the month and day, e.g., B(DocK) = May 29.) What is the image of each member of your group?
    🔗
    If time: How would this be different if we changed the domain to be just the people in our class?

    (c)

    For all \(n\in\mathbb{Z}\text{,}\) \(g(n)= n^3 - n \pmod{3}\text{.}\) (Here we mean the remainder \(r\in\{0,1,2\}\) when \(n^3-n\) is divided by \(3\text{.}\)) Determine the images of \(0,1,2,\) and \(5\) under \(g\text{.}\) What is the pre-image of \(0\text{?}\) What is the pre-image of \(1\text{?}\)
