    Chapter 3 Sets

    Handout Sets And Notation
    

    What is a Set? What Are the Symbols \(\in, \notin, \subseteq, \subset, \not\subseteq, = ?\)

    There’s a lot of notation that comes with sets!
    🔗
    🔗

    Definition 3.1.

    A set is an unordered collection of distinct objects which are called elements.
    🔗
    • If \(x\) is an element of a set \(S\text{,}\) we write \(x\in S\text{.}\) This is read “\(x\) in \(S\)”.
      🔗
      🔗
    • If \(x\) is not an element of a set \(S\text{,}\) we write \(x\notin S\text{.}\) This is read “\(x\) is not in \(S\)”.
      🔗
      🔗
    • If every element of \(A\) is also an element of \(B\) then \(A\) is a subset of \(B\text{,}\) denoted \(A\subseteq B\) and read “\(A\) is a subset of \(B\)”.
      🔗
      🔗
    • If \(A\subseteq B\) and \(A\neq B\text{,}\) then we write \(A \subset B\) and we say “\(A\) is a proper subset of \(B\)”.
      🔗
      🔗
    • If \(A\) is not a subset of \(B\) then we write \(A\not\subseteq B\) and say “\(A\) is not a subset of \(B\)”. This means there exists an \(x\in A\) such that \(x\notin B\text{.}\)
      🔗
      🔗
    • If \(A\) and \(B\) have the exact same elements, we write \(A=B\text{.}\) This is read as “\(A\) equals \(B\)”.
      🔗
      🔗
    🔗
    🔗

    Handout Roster Notation and Set Builder Notation
    

    Remark 3.4.

    • Roster notation is when we list all the elements, or list enough elements so that pattern is obvious and use \(\dots\) (dots). E.g., \(\{1,4,9,16,25,\dots\}\text{.}\)
      🔗
      🔗
    • Set builder notation is when we define the elements by a rule. E.g., \(\{n^2: n\in\mathbb{N}\}\text{.}\) or \(\{x \in \mathbb{Z}: 6\mid x\} \text{.}\)
      🔗
      🔗
    🔗
    🔗

    Handout Proving \(A\subseteq B\text{:}\) The “Choose an Element Method”
    

    The notation \(A\subseteq B\) is read “\(A\) is a subset of \(B\)” and means that if \(x\in A\) then \(x\in B\text{,}\) that is, every element of \(A\) is also an element of \(B\text{.}\)
    🔗
    Thus, if we want to prove that \(A\subseteq B\text{,}\) we are proving a conditional statement, i.e., an “if - then” statement. We’ll do a direct proof of this conditional statement. So, we’ll assume the hypothesis, and show the conclusion.
    🔗
    More specifically, we’ll start with an arbitrary \(x\) such that \(x\in A\text{,}\) and we’ll show \(x\in B\text{.}\) Let’s consider the following theorem.
    🔗

    Theorem 3.6.

    If \(A = \{x\in\mathbb{Z} \mid x \equiv 2 \pmod{4}\} \) and \(B =\{x\in\mathbb{Z} \mid x \equiv 0 \pmod{2}\}\) then \(A\subseteq B\text{.}\)
    🔗
    🔗

    Activity 3.7.

    Prove Theorem 3.6.
    🔗

    (a)

    Start with a pre-proof analysis. Consider listing the elements in \(A\) and the elements in \(B\) to see if you believe the conjecture. Then, choose an arbitrary element of \(A\text{,}\) e.g., “Let \(x\in A\text{.}\) So \(x\in \mathbb{Z}\) and \(x\equiv 2 \pmod{4}\text{.}\)” Work to show that this \(x\) is in \(B\text{,}\) that is \(x\equiv 0 \pmod {2}\text{.}\)
    🔗
    🔗

    (b)

    (If time:) It’s actually true that \(A\subset B\text{.}\) What would you add to your proof to prove this?
    🔗
    🔗
    🔗

    Remark 3.8.

    To say \(A = B\) is to say that \(A\) and \(B\) contain exactly the same elements. Said differently, it means these two things:
    1. Every element in \(A\) is also in \(B\) (which means \(A\subseteq B\) ), and
      🔗
      🔗
    2. Every element in \(B\) is also in \(A\) (which means \(B\subseteq A\) ).
      🔗
      🔗
    Indeed, a slick way to prove that \(A=B\) is to prove both \(A\subseteq B\) and \(B\subseteq A\text{,}\) both of which can be done using the “choose an element” method.
    🔗
    🔗

    Theorem 3.9.

    The sets \(A = \{5k+11: k\in\mathbb{Z} \}\) and \(B = \{x\in\mathbb{Z}: x\equiv 1\pmod{5}\}\) are equal.
    🔗
    🔗

    Activity 3.10.

    Prove Theorem 3.9.

    DeMorgan’s Laws.

    DeMorgan’s Laws are an important notion about taking complements of unions and intersections.
    🔗
    🔗

    Activity 3.12.

    In each of the following Venn diagrams, shade \((A\cap B)^C \text{,}\) \(A^c \cap B^c \text{,}\) \((A\cup B)^C \text{,}\) and \(A^C \cup B^C\text{.}\)
    🔗
    🔗
    Your book does a proof that two of these sets are equal on pages 114-115. Let’s sketch the other one.
    🔗

    Theorem 3.14.

    Suppose \(A\) and \(B\) are subsets of a universal set \(U\text{.}\) Then
    \begin{equation*} (A\cap B)^c = A^c \cup B^c. \end{equation*}
    🔗
    🔗

    Showing Disjointness.

    Roughly, two sets are disjoint if they have no elements in common. The official definition is given in Definition 3.15.
    🔗

    Definition 3.15.

    Two sets \(A\) and \(B\) are disjoint provided that \(A\cap B = \emptyset\text{.}\)
    🔗
    🔗
    Typically, if we want to prove two sets are disjoint we will use a proof technique called “proof by contradiction”. It seems hard to prove that something is equal to the empty set. Instead, we’ll assume that \(A\cap B \neq \emptyset\text{.}\) This gives an element \(x\in A\cap B\text{.}\) We work from here to a contradiction, or something that can’t possibly be true, so the original assumption must have been wrong.
    🔗
    🔗

    Theorem 3.16.

    If \(A = \{x\in\mathbb{Z} \mid x \equiv 2 \pmod{4} \}\) and \(B = \{y\in\mathbb{Z} \mid y\equiv 3 \pmod{6}\}\) then \(A\cap B = \emptyset\text{.}\)
    🔗
    🔗

    Prove Theorem 3.16.
