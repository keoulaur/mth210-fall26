    Let’s start with disproving. Recall the following definitions.
    🔗
    A function \(f: A\to B\) is injective if for all \(a_1,a_2\in A\text{,}\) if \(f(a_1) = f(a_2)\) then \(a_1 = a_2\text{.}\)
    🔗
    A function \(f: A\to B\) is surjective if, for every \(b\in B\text{,}\) there exists some \(a\in A\) such that \(f(a) = b\text{.}\)

    Theorem 8.11.

    Let \(f: \R - \{1\} \to \R - \{0\}\) be defined by \(f(x) = \dfrac{1}{1-x}\) for all \(x \in \R - \{1\}\text{.}\) Then \(f\) is a bijection.
    🔗
    🔗

    Proof.
    Let \(f: \R - \{1\} \to \R - \{0\}\) be defined by \(f(x) = \dfrac{1}{1-x}\) for all \(x \in \R - \{1\}\text{.}\) We will prove that \(f\) is a bijection by proving that it is both a surjection and an injection.
    🔗
    We will first show that \(f\) is a surjection. So, let \(z \in \mathbb{R} - \{0\}\) be any element of the codomain of \(f\text{.}\) Let \(x = \frac{z-1}{z}\text{.}\) We will show that \(x \in \R - \{1\}\) and that \(f(x) = z\text{.}\)
    🔗
    We begin by showing that \(x\) is in the domain of \(f\text{.}\) To do this, we will show that \(x \in \R\) and \(x \neq 1\text{.}\) Real numbers are closed under subtraction and division (as long as they are nonzero), and by assumption \(z \neq 0\text{,}\) so \(x \in \mathbb{R}\text{.}\) Next we will show that \(x \neq 1\text{.}\) To see this, suppose that \(x = 1\text{.}\) Using algebra, we find that \(1 = \frac{z-1}{z}\text{,}\) which simplifies to \(0 = -1\text{,}\) a contradiction. Thus \(x \neq 1\text{,}\) and so \(x \in \mathbb{R} - \{1\}\text{.}\)
    🔗
    Now we will show that \(f(x) = z\text{.}\) Using algebra,
    \begin{align*} f\left(\frac{z-1}{z}\right) \amp= \dfrac{1}{1 - \left(\frac{z-1}{z}\right)} \\ \amp= \dfrac{1}{\frac{z}{z} - \frac{z-1}{z}} \\ \amp= \dfrac{1}{\frac{z- (z-1)}{z}} \\ \amp= \dfrac{1}{\frac{1}{z}} = z. \end{align*}
    🔗
    Thus for each \(z\) in the codomain of \(f\text{,}\) there exists \(x = \frac{z-1}{z}\) in the domain of \(f\) such that \(f(x) = z\text{.}\) Therefore by definition, \(f\) is a surjection.
    🔗
    We will now show that \(f\) is an injection. So, suppose that \(f(x) = f(y)\) for some \(x, y \in \mathbb{R} - \{1\}\text{.}\) We will show that \(x = y\text{.}\) Using algebra,
    \begin{align*} f(x) \amp= f(y) \\ \dfrac{1}{1-x} \amp= \dfrac{1}{1-y} \\ 1-x \amp= 1-y \\ x \amp= y. \end{align*}
    Thus, for all \(x\) and \(y\) in the domain of \(f\text{,}\) whenever \(f(x) = f(y)\text{,}\) we must have \(x = y\text{.}\) Therefore \(f\) is an injection.
    🔗
    Because we have shown that \(f\) is both a surjection and an injection, we have shown that \(f\) is a bijection.
